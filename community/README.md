# Kuratierter Community-Katalog

`catalog.json` enthält ausschließlich geprüfte Pakete aus diesem Repository. Jeder Eintrag nennt Paket-ID, Version, Sprache, Typ, Lizenz, HTTPS-Adresse und SHA-256 der exakten Datei. Änderungen an Paketen benötigen eine neue Prüfsumme; veröffentlichte Paketversionen möglichst unter neuem Dateinamen ablegen.

Einreichungen: https://github.com/Burigames/storynator/issues

Bitte `.storynator-pack`, Beschreibung, Urheber, Quellen und Lizenz angeben. Vor Aufnahme prüfen: Nutzungsrechte, Paketvalidierung, Import in leeres Projekt, enthaltene Texte/Bilder, Abhängigkeiten und Spoiler. Keine Einträge in reinen Kategorie-Presets, keine externen Bildpfade, keine ausführbaren Erweiterungen. Dateien werden ausschließlich nach manueller Prüfung in den Katalog aufgenommen.

Meldungen defekter Pakete ebenfalls über Issues mit Paket-ID und Version. Ein Katalogeintrag ist keine Garantie für die rechtliche Verwendbarkeit; die konkrete Lizenz ist maßgeblich.
